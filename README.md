

\# Aircraft Fuel and Range Management (AFRM)



\## Project Overview



This repository contains a C++ prototype developed for

Assignment 1 of the Aerospace Application Development module.



The application is intended to demonstrate software development

environment configuration, algorithm design, verification and

sustainable software engineering.



\*\*Disclaimer:\*\* This is an educational prototype using simulated

flight and fuel data. It is not suitable for operational flight

planning or aircraft fuel management.



\## Development Environment



\- Language: C++20

\- IDE: Microsoft Visual Studio Community 2026 (18.11.0)

\- Compiler: Microsoft Visual C++ (MSVC)

\- Build system: CMake

\- Version control: Git



Exact compiler and CMake versions will be documented separately.



\## Current Development Status



The C++ development environment has been configured and a

minimal executable has been compiled and run successfully.



The AFRM fuel-management functionality has not yet been

implemented.



\## Planned Functionality



\- Validate simulated flight and fuel inputs

\- Calculate trip fuel and contingency fuel

\- Calculate total required fuel

\- Calculate remaining fuel margin

\- Classify fuel status

\- Estimate theoretical planning range
